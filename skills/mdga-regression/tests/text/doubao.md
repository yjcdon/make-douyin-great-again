# 豆包文案草稿

## DOUBAO-01 填写草稿并等待发送

- **前提与步骤**　豆包新聊天可使用，扩展已开启「显示豆包提取文案按钮」。记录当前提示词和正在播放的作品 ID，点击「提取文案」。核对新标签页的输入框和对话区，再切回抖音看播放器。涉及播放器入口改动时，覆盖独立作品页。测试操作停在草稿。
- **预期结果**　原视频暂停。豆包新标签页的草稿第一行是 `https://www.douyin.com/video/作品ID`，换行后是配置的提示词。输入框保留可编辑草稿，聊天区无新增消息。

## DOUBAO-02 切换作品和草稿隔离

- **前提与步骤**　对一条视频按 `DOUBAO-01` 生成草稿并保留该测试标签页。切回原抖音页，从推荐流切换作品或从精选列表改开另一条视频弹层，再次点击「提取文案」。分别查看两个测试标签页和抖音播放器。
- **预期结果**　切回抖音后当前作品的提取按钮可用。两页草稿各自包含对应作品链接，第二次操作保留第一份草稿且聊天区均无新增消息。

## DOUBAO-03 提示词和按钮设置

- **前提与步骤**　记录原提示词和豆包按钮开关。保存一段容易识别的临时提示词，关掉再打开扩展菜单核对保存结果。关闭再开启豆包按钮，用 `DOUBAO-01` 检查新草稿。结束后恢复原提示词和开关。
- **预期结果**　提示词保存后可重新读到，新草稿使用刚保存的文本。豆包按钮随开关即时隐藏或恢复，已开启的下载按钮保持可见。
