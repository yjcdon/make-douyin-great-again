# 精选封面网格

## GRID-01 首屏大卡隐藏并释放媒体源

- **前提与步骤**　选原生精选首屏有左侧大卡和右侧普通封面的窗口宽度。刷新精选列表，观察首屏和补位情况。如果大卡挂载了播放器，在开发者工具检查该大卡的视频状态及媒体源。
- **预期结果**　左侧大卡隐藏，普通封面补上原位置。大卡里的视频处于暂停状态，`src`、`srcObject` 和 `<source src>` 已清空。若样本只有静态大卡，记录布局结果，媒体释放另选带播放器的样本核验。

## GRID-02 封面网格与播放器往返

- **前提与步骤**　从精选列表记录一张普通封面的作品，点开播放，再关闭播放器回到列表。往下滚动后选另一张封面重复一次。
- **预期结果**　播放器打开的是所点作品，视频能播放。返回后封面布局可用，下方加载的封面也能点开。

## GRID-03 窄窗口的封面布局

- **前提与步骤**　用窄窗口打开精选列表，选择原生布局只有一列或首屏只有一张普通卡的样本。等待首张封面加载，再点开作品。
- **预期结果**　封面能从首屏显示出来，仍可点击播放。
