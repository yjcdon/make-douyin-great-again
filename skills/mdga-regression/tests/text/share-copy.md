# 精简分享

## SHARE-01 复制标题和原短链接

- **前提与步骤**　选一个标题含话题、可用原生 `V` 快捷键分享的视频。记录作品标题和 ID，焦点离开输入框后按 `V`，将剪贴板内容粘贴到临时纯文本。打开复制出的短链核对作品 ID。全测时覆盖推荐流、视频详情和精选页弹层中支持 `V` 的入口。
- **预期结果**　剪贴板正好两行。第一行是去掉话题的标题，第二行是抖音的 `v.douyin.com` 短链，打开后对应同一作品。原生分享口令和打开提示已移除。
- **回退路径**　验证复制弹窗相关改动时，用同一次分享文案触发抖音的手动复制回退。剪贴板可写时直接得到两行精简文案。浏览器拒绝写入时，弹窗内仍是相同的两行。

## SHARE-02 普通复制与输入框

- **前提与步骤**　按 `V` 复制分享后，立即在同一抖音标签页选择普通文本并按 `⌘C` 或 `Ctrl+C`。核对剪贴板，再把焦点放进搜索框输入 `v`，核对输入框和剪贴板。
- **预期结果**　普通复制得到所选文字。输入框正常输入 `v`，剪贴板保留普通复制结果。
