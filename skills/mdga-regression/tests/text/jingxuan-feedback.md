# 精选快捷反馈

## FEEDBACK-01 快捷反馈入口

- **前提与步骤**　在精选列表把鼠标移入再移出一张普通封面，然后用 Tab 聚焦快捷按钮。手动打开并关闭同卡片的三点菜单。滚动后在新封面重复观察。
- **预期结果**　封面左上角的「不感兴趣」按钮随悬停显示或隐藏，键盘聚焦时可见，位置与当前封面对齐。原生三点菜单可手动打开。

## FEEDBACK-02 提交反馈并撤销

- **前提与步骤**　使用已登录的账号和获准提交反馈的作品。记录目标作品 ID 和相邻卡片，点击目标封面上的「不感兴趣」，随后点抖音原生「撤销」。排查目标串卡时，点击前开启网络记录，事后核对原生提交携带的 `aweme_id`。
- **预期结果**　目标卡片原位显示抖音的「视频已移除」和「撤销」，相邻卡片保持原样。如核对了请求，`aweme_id` 与目标作品一致。撤销后恢复原封面，悬停时快捷按钮再次可见。

## FEEDBACK-03 原生菜单不可用时提示重试

- **前提与步骤**　在已获准反馈的作品上复现原生三点菜单不可用。可在测试标签页临时移除该卡片三点菜单的标识类，模拟入口找不到的情况。开启网络记录，点击封面上的快捷按钮，观察提示和卡片状态。结束后恢复页面。
- **预期结果**　按钮提示「提交失败，点击重试」，目标作品和相邻作品保持原状，本次反馈提交请求数为零。若出现真实反馈，立即用原生「撤销」恢复并记录结果。
