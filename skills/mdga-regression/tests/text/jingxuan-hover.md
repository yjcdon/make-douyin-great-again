# 精选悬浮预览

## HOVER-01 关闭悬浮预览时保留原生操作

- **前提与步骤**　记录「关闭悬浮浏览」的原值，勾选该选项。在精选列表悬停普通视频封面，移到右下角三点并打开原生菜单。收起菜单，点击封面播放。结束后恢复原设置。
- **预期结果**　悬停时封面保持静止，三点菜单能打开，点击封面后所选作品能播放。

## HOVER-02 切换悬浮预览设置

- **前提与步骤**　选择支持原生悬浮预览的普通视频封面。记录原设置，在扩展菜单取消勾选「关闭悬浮浏览」，回到同一张封面悬停。重新勾选后再次悬停，刷新列表后复查并恢复原设置。
- **预期结果**　取消勾选后可触发原生预览。重新勾选后，已有预览停止，再次悬停保持封面静止，刷新后设置仍生效。
