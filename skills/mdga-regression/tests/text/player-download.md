# 播放器与视频下载

## PLAYER-01 下载当前视频

- **前提与步骤**　打开一个可正常播放、标题含话题的短视频详情。确认下载按钮开启。记下作品 ID、标题和时长，播放中点击「下载视频」，先看原播放器状态，再检查浏览器下载列表和下载完成的文件。用另一条短视频从暂停状态重做。
- **预期结果**　每次点击生成一条对应作品的下载记录。完成的 MP4 可播放，画面和时长与原视频相符，文件名使用去掉话题的标题。播放中的视频继续播放，原已暂停的视频保持暂停。

## PLAYER-02 切换作品后下载

- **前提与步骤**　在推荐流切到另一条作品，记录新作品的标题和 ID，点击当前作品的「下载视频」。从精选页打开另一张视频卡的弹层重复核对。若改动涉及文件名，可选一条只有话题的可下载样本补测。
- **预期结果**　下载按钮随当前作品就位且只出现一次。下载文件对应新作品。没有可用标题时，文件名使用 `douyin-作品ID.mp4`。

## PLAYER-03 下载开关与清屏

- **前提与步骤**　在视频详情记录原清屏状态，显示作品信息。打开扩展菜单，记录下载和豆包按钮设置，开启两项。关闭「显示下载视频按钮」，关闭再打开菜单查看设置，然后重新开启。回到播放器按两次 `J`，结束后恢复原设置和清屏状态。
- **预期结果**　下载按钮随开关即时隐藏或恢复，重新打开菜单仍显示所选状态。豆包按钮在下载开关切换期间可见。清屏时两项随作品信息隐藏，退出清屏时一起恢复。
