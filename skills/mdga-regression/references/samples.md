# 测试样本入口

使用本轮能正常打开的公开作品。首次确认可复用后，再在表中补具体作品链接和已验证的条件。

| 入口 | 怎样选样本 |
| --- | --- |
| [抖音精选列表](https://www.douyin.com/jingxuan) | 首屏布局选能显示原生大卡和普通封面并排的窗口。悬浮和三点菜单用普通视频卡片。点击封面获得同一条作品的精选播放器入口。实际反馈使用用户授权的作品。 |
| [抖音推荐](https://www.douyin.com/?recommend=1&from_nav=1) | 进入推荐流后选两条标题明显不同、可播放的视频，记录切换前后的作品 ID。 |
| [作品独立详情一](https://www.douyin.com/video/7702333658082141873) · [作品独立详情二](https://www.douyin.com/video/7704303782242677929) | 两条均验证过下载及保持播放状态。详情一也用于检查豆包草稿，详情二的标题与话题标签紧挨着，适合核对文件名。 |
| [豆包新聊天](https://www.doubao.com/chat) | 草稿交接从抖音播放器的「提取文案」触发。用当前作品地址和扩展设置中的提示词核对，测试时停在输入框。 |

列表或登录状态改变时，记录实际入口和样本条件。修复具体故障时，优先复用用户报告的作品及其入口。
