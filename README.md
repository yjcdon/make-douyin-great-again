# make-douyin-great-again

在抖音网页版播放作品时，按站内快捷键 `V`，复制结果为两行，第一行是标题，第二行是抖音生成的原短链接。



安装

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择本目录下的 `extension` 文件夹。
3. 刷新已打开的抖音网页，播放视频后按 `V`，再粘贴查看结果。

扩展仅在 `www.douyin.com` 上运行。它沿用抖音的分享动作，在本地移除口令、话题和打开提示。口令中的日期、识别码和时间标记可以按不同顺序出现。常规复制以及其他格式的分享文案保持原样。

扩展将分享文案中第一个后面有文字的 `#` 视为话题起点。标题本身带有这类井号时，标题可能被截短。
