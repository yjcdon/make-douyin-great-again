# Make Douyin Great Again

Make Douyin Great Again（MDGA）是一款用于浏览和处理抖音网页视频的浏览器扩展。它可以下载视频、复制精简分享链接、调整精选页布局，也可以将作品链接和提示词填入豆包，供你确认后发送并提取文案。

[下载最新版扩展](https://github.com/yjcdon/make-douyin-great-again/releases/latest) · [隐私政策](https://yjcdon.github.io/privacy/make-douyin-great-again/)

## 功能

- **用豆包提取文案。** 播放视频时，点击作品信息上方的豆包图标。扩展会暂停视频，在豆包新标签页填入作品链接和提示词。检查草稿后，点击豆包的「发送」。默认提示词要求逐句输出视频文案。可在扩展菜单中修改提示词或关闭按钮。
- **下载视频。** 点击左下角作品信息上方的下载图标，把当前作品的可用 MP4 交给浏览器下载。文件以去掉话题标签的作品标题命名，取不到标题时使用作品 ID。进度可在浏览器下载列表查看，视频会保持原有播放状态。下载按钮默认显示，可在扩展菜单中关闭。
- **精简分享文案。** 播放作品时按抖音快捷键 `V`，粘贴后第一行是作品标题，第二行是抖音原短链接。扩展会移除分享口令、话题标签和打开提示。
- **精选页封面网格。** 隐藏首屏左侧大卡并卸载它的媒体源，普通封面自动补位。点击任一封面即可播放。
- **一键标记不感兴趣。** 在抖音精选页，把鼠标移到封面，点击左上角的拇指图标。操作后可通过卡片下方的抖音原生「撤销」恢复。
- **关闭封面悬浮预览。** 默认关闭精选页的悬浮预览，点击封面仍可观看。想恢复预览时，点击浏览器工具栏的 MDGA 图标，取消勾选「关闭悬浮浏览」。

## 安装

适用于 Chrome 111 及以上版本，也可在 Microsoft Edge 中按以下步骤加载。扩展作用于 `www.douyin.com`。

1. 在最新版下载页的 **Assets** 中下载 `make-douyin-great-again-v*.zip` 并解压。
2. 在地址栏打开 `chrome://extensions`，Edge 用户打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 刷新已打开的抖音页面。

从源码安装时，选择仓库中的 [`extension/`](extension/) 文件夹。

升级时，将新版 ZIP 解压到原来加载的目录，在扩展管理页点击「重新加载」，再刷新抖音。

## 使用提示

豆包和下载按钮随播放器的「清屏」设置一起隐藏或恢复，可按 `J` 切换。浏览器需要「管理下载内容」权限才能启动视频下载。

分享精简适用于扩展能识别的抖音分享文案。标题里有 `#` 时，扩展可能把后面的文字视为话题。
