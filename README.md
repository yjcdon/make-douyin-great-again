# Make Douyin Great Again

Make Douyin Great Again（MDGA）是抖音网页版浏览器扩展。你可以从播放器下载 MP4、按 `V` 复制标题和短链接、把作品链接和提示词填入豆包草稿，也可以调整精选页的封面和预览。

[下载最新版扩展](https://github.com/yjcdon/make-douyin-great-again/releases/latest) · [版本复盘](docs/versions/README.md) · [隐私政策](https://yjcdon.github.io/privacy/make-douyin-great-again/)

## 功能

- **下载抖音视频。** 点击作品信息上方的下载图标，浏览器开始下载当前作品的 MP4，视频保持原来的播放或暂停状态。文件名使用去掉话题标签的标题，取不到标题时使用作品 ID。
- **用豆包提取文案。** 点击作品信息上方的豆包图标，扩展暂停视频并在豆包新标签页填入作品链接和提示词。检查草稿后，由你点击「发送」。提示词可在扩展菜单修改，默认要求每句一行。
- **精简分享文案。** 播放作品时按抖音快捷键 `V`，复制作品标题和抖音原短链接，各占一行。剪贴板写入受限时，复制弹窗也会显示这两行。
- **精选页封面网格。** 隐藏首屏左侧大卡并卸载它的媒体源，普通封面自动补位。点击任一封面即可播放。
- **一键标记不感兴趣。** 在抖音精选页，把鼠标移到封面，点击左上角的拇指图标。操作后可通过卡片下方的抖音原生「撤销」恢复。
- **关闭封面悬浮预览。** 默认关闭精选页的悬浮预览，点击封面仍可观看。想恢复预览时，点击浏览器工具栏的 MDGA 图标，取消勾选「关闭悬浮浏览」。

## 安装

使用 Chrome 111 或更高版本。Microsoft Edge 也可手动加载扩展。

1. 在最新版下载页的 **Assets** 中下载 `make-douyin-great-again-v*.zip` 并解压。
2. 打开扩展管理页。Chrome 用 `chrome://extensions`，Edge 用 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 刷新已打开的抖音页面。

从源码安装时，选择仓库中的 [`extension/`](extension/) 文件夹。

升级时，将新版 ZIP 解压到原来加载的目录，在扩展管理页点击「重新加载」，再刷新抖音。

## 使用提示

推荐流、独立视频页和精选视频弹层都提供豆包和下载按钮。两个按钮可在扩展菜单单独开关，也会随播放器的 `J` 清屏设置隐藏或恢复。下载进度在浏览器下载列表查看，启动下载需要「管理下载内容」权限。

分享精简适用于扩展能识别的抖音分享文案。标题里的 `#` 及其后文字可能会按话题标签处理。
