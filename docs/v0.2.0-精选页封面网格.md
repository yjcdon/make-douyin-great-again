# v0.2.0 · 精选页封面网格

2026-11-10

## S · 背景

精选页首屏的左侧大卡占用多个封面的位置。只隐藏卡片画面时，其播放器仍可能挂载媒体源。

## T · 目标

用普通封面填补首屏空间，让封面继续按抖音原有方式打开作品。

## A · 做法

识别左侧大卡和相邻普通封面后，把首屏整理为封面网格。暂停隐藏的大卡播放器并卸载其媒体源。窄窗口或首屏封面不足时，保留可用的原生布局。

## R · 结果

本版发布了普通封面自动补位和隐藏播放器的媒体清理，并同步更新扩展的安装与升级说明。
