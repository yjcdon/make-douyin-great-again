# v0.3.0 · 豆包提取视频文案

2026-11-15

## S · 背景

用豆包提取抖音视频文案时，需要先拿到作品链接、打开豆包，再填写提示词。

## T · 目标

在抖音播放器里提供「提取文案」入口，一次操作完成作品和提示词的交接。

## A · 做法

在推荐和精选的视频播放器加入豆包按钮。点击后暂停当前作品，按新标签页保存作品直链和提示词。豆包输入框就绪后填入内容，当时的流程会自动发送。扩展菜单提供按钮开关和提示词设置。

## R · 结果

用户可以从视频直接发起文案提取，默认提示词要求一句一行。发送流程在 [v0.4.3](v0.4.3-豆包草稿确认后发送.md) 改成用户确认后发送。
