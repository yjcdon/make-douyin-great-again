# v0.2.1 · 统一扩展显示名称

2026-11-15

## S · 背景

浏览器扩展管理页和扩展弹窗标题仍使用仓库名 `make-douyin-great-again`。

## T · 目标

在用户接触到的浏览器界面统一使用产品名 Make Douyin Great Again。

## A · 做法

同步更新扩展清单的名称和弹窗 HTML 标题。

## R · 结果

扩展管理页与弹窗标题使用同一个产品名，用户在安装及管理时能够对应上项目名称。
