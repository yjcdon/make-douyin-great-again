# 抖音精选页快捷提交不感兴趣

在精选列表中，鼠标移入封面时，左上角显示拇指向下按钮「不感兴趣」。鼠标移出时隐藏按钮，键盘聚焦时也可操作。

点击后，扩展使用当前抖音网页会话异步提交该作品的反馈。等待期间同一作品只提交一次。后台确认成功后，封面原位显示深色遮罩和「内容不感兴趣」。提交失败时保留封面，用户可以重试。

提交结果按作品 ID 保存在当前页面内，封面切换为视频预览或列表重新渲染后仍对应同一作品。刷新页面后，封面显示以抖音返回的列表为准。

原生播放器的请求为 `POST /aweme/v1/web/commit/dislike/item/`，表单中的 `aweme_id` 是作品 ID。扩展以 HTTP 成功且响应中 `status_code: 0` 作为反馈成功的依据。

## 验收

- 鼠标移入封面显示按钮，移出后隐藏。键盘聚焦时可以触发按钮。
- 点击按钮提交对应作品。后台确认成功后，目标封面原位显示遮罩。
- 滚动加载和卡片复用时，遮罩跟随作品 ID。同一作品的请求完成前，重复点击只发送一次。
- 网络失败或抖音返回失败时，保留封面并允许重试。
