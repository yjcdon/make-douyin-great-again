# 抖音精选页快捷提交不感兴趣

在精选列表中，鼠标移入封面时，左上角显示拇指向下按钮「不感兴趣」。鼠标移出时隐藏按钮，键盘聚焦时也可操作。

点击后，扩展触发同一张卡片右下角三点菜单里的原生「不感兴趣」。快捷操作期间菜单在后台处理，手动点击三点仍可打开菜单。抖音负责提交反馈、原位显示「视频已移除」遮罩及「撤销」。卡片移除时隐藏扩展按钮，原生撤销恢复封面后重新显示。

已在登录后的精选列表实测，程序触发原生菜单项后，请求 `POST /aweme/v1/web/commit/dislike/item/` 携带目标作品的 `aweme_id`，返回 HTTP 200 和 `status_code: 0`，卡片保留在原位。

## 验收

- 鼠标移入封面显示按钮，移出后隐藏。键盘聚焦时可以触发按钮。
- 点击按钮触发对应作品的原生操作。原位显示抖音的「视频已移除」遮罩和「撤销」。
- 点击原生「撤销」后，恢复的封面可再次使用扩展按钮。
- 原生菜单无法打开时，扩展按钮提示重试。
