# v0.3.1 · 切回抖音时恢复豆包按钮

2026-11-15

## S · 背景

从豆包切回抖音时，推荐流播放器的活动标记有时会变动，「提取文案」按钮因此偶尔消失。

## T · 目标

让用户切回抖音后能继续提取当前作品的文案。

## A · 做法

从播放器所属容器读取作品 ID。抖音标签页重新可见时，再检查一次按钮是否应该显示。

## R · 结果

用户切回抖音后，可以继续对当前作品使用「提取文案」。
