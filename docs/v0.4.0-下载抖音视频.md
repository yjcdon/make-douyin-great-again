# v0.4.0 · 下载抖音视频

2026-11-16

## S · 背景

在抖音网页看视频时，用户需要一个保存当前作品的入口。播放器已经有豆包按钮，可以共用作品信息上方的位置。

## T · 目标

从播放器下载当前作品的 MP4，保留原来的播放或暂停状态，由浏览器管理下载进度。

## A · 做法

复用页面已加载的完整播放地址，交给 Chrome 下载。文件名优先使用作品标题，取不到标题时使用作品 ID。下载与豆包按钮并排显示，并随抖音的清屏设置隐藏或恢复。

## R · 结果

本版交付了播放器下载入口和浏览器下载进度。README 补充了下载权限说明。
