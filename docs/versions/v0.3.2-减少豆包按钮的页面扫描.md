# v0.3.2 · 减少豆包按钮的页面扫描

2026-11-15

## S · 背景

豆包按钮开启后，旧版会监听其他抖音页面的 DOM 变化，这些页面也会触发寻找播放器的检查。

## T · 目标

把页面监听限制在可能显示豆包按钮的入口。

## A · 做法

根据扩展开关和当前地址决定是否开启监听。独立作品地址、作品弹层和推荐流符合条件时启用监听。站内跳转或切回标签页时重新判断。

## R · 结果

豆包按钮的扫描随播放器入口启停，减少普通列表等页面处理无关变化的工作量。
