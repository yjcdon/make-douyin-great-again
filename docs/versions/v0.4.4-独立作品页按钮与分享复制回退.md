# v0.4.4 · 独立作品页按钮与分享复制回退

2026-11-27

## S · 背景

全量回归发现，独立作品页能播放视频，但缺少下载和豆包按钮。按 `V` 分享时，抖音有时会打开手动复制弹窗，弹窗里的文案仍包含分享口令和打开提示。

## T · 目标

在独立作品页恢复两个按钮，让抖音的分享复制回退也能保留两行精简文案。

## A · 做法

在独立作品页复用播放器工具栏，以该页的作品信息读取标题和已加载的播放地址。识别 `V` 触发的分享弹窗后，尝试把精简内容直接写入剪贴板。浏览器拒绝写入时，弹窗里也提供精简文案。

## R · 结果

在 macOS Chrome 复测了独立作品页的开关、`J` 清屏、豆包草稿和下载。两次下载分别保留了原来的播放与暂停状态，下载文件可解码且时长吻合。推荐流、独立作品页和精选弹层都复制出了两行文案，并使用原始分享样本验证了弹窗回退。
