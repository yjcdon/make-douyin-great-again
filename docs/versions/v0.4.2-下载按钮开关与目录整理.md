# v0.4.2 · 下载按钮开关与目录整理

2026-11-17

## S · 背景

播放器增加下载后，用户需要单独控制这个按钮。精选页、播放器和弹窗相关文件也逐渐增多，扩展根目录开始堆积不同功能的入口。

## T · 目标

允许用户单独隐藏下载按钮，并让代码目录对应实际功能。

## A · 做法

在扩展弹窗加入「显示下载视频按钮」，默认开启，切换后同步到播放器。将相关源码归入播放器、精选页和弹窗目录，并更新清单引用。

## R · 结果

用户可以关闭下载入口，豆包按钮仍由自己的开关控制。维护时可以按功能定位代码，扩展清单指向整理后的入口。
