# v0.1.1 · 精简分享与精选快捷操作

2026-11-10

## S · 背景

抖音网页的原生分享文案包含口令、话题和打开提示，转发前常要手动整理。精选页的「不感兴趣」藏在三点菜单里，浏览封面时还会触发预览。

## T · 目标

用原生 `V` 快捷键复制标题和短链接，让精选页可以一键提交反馈，并允许用户控制悬浮预览。

## A · 做法

在用户按 `V` 后处理识别到的抖音分享文案。精选封面左上角增加「不感兴趣」，点击时触发该作品的原生菜单项。扩展菜单增加「关闭悬浮浏览」，默认开启。

## R · 结果

首个正式版本交付了精简分享、精选反馈和预览开关。精选页实测记录显示，反馈请求使用了目标作品 ID，返回成功，卡片原位显示可撤销的反馈结果。
