# v0.4.1 · 下载文件名去掉话题标签

2026-11-16

## S · 背景

部分作品把话题标签紧贴在标题后。旧版只识别以空白分隔的话题，这类标签会跟着进入下载文件名。

## T · 目标

让紧贴标题的话题标签也能从下载文件名中移除。

## A · 做法

从作品文案的首行或首个有效话题符号处截取标题，再交给已有的文件名清理和下载流程。

## R · 结果

带话题的作品以去掉话题后的标题命名，标题后直接接 `#话题` 的写法也能处理。README 同步说明了这一命名行为。
