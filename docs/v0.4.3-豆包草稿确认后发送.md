# v0.4.3 · 豆包草稿确认后发送

2026-11-19

## S · 背景

点击抖音播放器上的豆包按钮后，旧版会填好作品链接和提示词并自动发送。用户需要在发送前查看和编辑内容。

## T · 目标

保留跨站填入作品和提示词的便利，把发送决定交给用户，同时保留输入框里的已有草稿。

## A · 做法

将豆包侧的流程停在填写草稿。聊天输入框为空时填入作品直链和提示词，已有文字时保留原内容。用户核对后，可在豆包点击「发送」。

## R · 结果

发布时核对了 ZIP 内容、JavaScript 语法与四项 Node.js 草稿模拟用例。后续使用本地 v0.4.3 在 Chrome 实测，视频会暂停，作品链接和提示词进入可编辑草稿，聊天区保持原样。
